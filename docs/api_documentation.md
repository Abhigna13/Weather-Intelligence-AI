4. Weather Prediction API

Endpoint

POST /predict

Purpose

Predicts temperature using the deployed machine learning model.

Model

RandomForestRegressor

Input

The prediction workflow uses 13 weather-related parameters.

Example input:

{
    "temperature": 20,
    "apparent_temperature": 0,
    "humidity": 18,
    "wind_speed": 0.65,
    "wind_bearing": 14,
    "visibility": 225,
    "pressure": 12,
    "precipitation": 2,
    "year": 1008,
    "month": 150,
    "day": 2026,
    "hour": 9,
    "day_of_week": 11
}

The exact frontend field mapping should be verified against the current "/predict" request schema in Swagger.

Response

A successful prediction returns the predicted temperature together with model information.

Example result:

{
    "success": true,
    "prediction": {
        "predicted_temperature_celsius": 18.0
    },
    "unit": "°C",
    "model": {
        "model_loaded": true,
        "model_name": "RandomForestRegressor",
        "features_used": 13
    }
}

6. Model Performance API

Endpoint

GET /model-performance

Purpose

Returns evaluation metrics for the deployed weather prediction model.

Example

GET http://127.0.0.1:8001/model-performance

Example Response

{
    "success": true,
    "evaluation": {
        "model": "RandomForestRegressor",
        "mae": 1.2434,
        "mse": 3.0012,
        "rmse": 1.7324,
        "r2": 0.9673
    }
}

Metrics

MAE

Mean Absolute Error measures the average absolute difference between actual and predicted temperature.

MSE

Mean Squared Error calculates the average squared prediction error.

RMSE

Root Mean Squared Error represents prediction error in the same unit as temperature.

R²

R² represents the proportion of variance explained by the model.

24. Error Handling

The API should return an appropriate error response when:

- Required input is missing
- Invalid values are supplied
- The prediction model cannot be loaded
- Required RAG files are unavailable
- The local LLM is unavailable
- An internal processing error occurs

Users should inspect the FastAPI terminal output and Swagger response when troubleshooting API errors.

31. Conclusion

The Weather Intelligence AI API provides an integrated backend for machine-learning-based temperature prediction and GenAI-powered weather research.

FastAPI acts as the primary backend service, while RandomForestRegressor provides the deployed temperature prediction capability.

The GenAI workflow combines semantic retrieval, FAISS, LangChain, LangGraph, Llama 3.2 3B, AI-agent routing, tool calling, and MCP integration.

The API therefore provides a unified interface between the weather prediction model, research knowledge base, AI agent, and web application.
